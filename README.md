# Мини-игры: Использование простых инструментов Javascript для реализации мини игр.

Коллекция простых браузерных мини-игр, реализованная на чистом HTML и CSS. Проект демонстрирует навыки адаптивной вёрстки, работы с Flexbox и решения типичных проблем выравнивания контента (разделение фона на всю ширину и центрирование контента в пределах 1201px).

## 🚀 Как запустить проект

### Вариант 1: Локальный запуск (через Live Server в VS Code)
1. Клонируйте репозиторий: `git clone 
2. Откройте папку проекта в редакторе кода (VS Code)
3. Установите расширение "Live Server" (если еще нет)
4. Нажмите кнопку "Go Live" в правом нижнем углу редактора
5. Проект откроется в браузере по адресу `http://127.0.0.1:5500`.

### Вариант 2: Просмотр без установки
Если не хотите ничего устанавливать, просто откройте файл `index.html` двойным кликом в любой папке.

## 🛠 Используемые технологии

- **HTML5** — семантическая разметка.
- **CSS3** — стилизация, Flexbox, адаптивная вёрстка.
- **SCSS** (опционально, если использовали) — препроцессор для удобства написания стилей.
- **SVG** — векторная графика (иконки звезд в меню).

## 📝 Особенности реализации и решенные задачи

В ходе разработки были решены следующие технические задачи:
- **Разделение фона и контента:** фон секции растягивается на 100% ширины экрана, в то время как контент ограничен контейнером шириной 1201px и выровнен по центру.
- **Адаптивность карточек:** карточки игр имеют одинаковую высоту в ряду за счет использования `align-items: stretch` у родителя и `flex-grow` у блока с изображением.
- **Растягивание изображений:** картинки внутри карточек заполняют отведенное пространство без искажений благодаря свойству `object-fit: cover`.
- **Оптимизация отступов:** уменьшены избыточные паддинги (с 48px до 16px) для лучшей читаемости
